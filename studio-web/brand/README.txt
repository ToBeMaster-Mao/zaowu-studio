造物 Studio / 品牌标识

设计：两段切面折带构成“造物”拼音首字母 Z。中间保留斜向负空间，让二维图形带有折叠、组装、成形的感觉；不依赖立方体、星星或具体模型题材。

文件
logo-mark.svg        彩色图形标识，透明背景，64 × 64 viewBox。
logo-mark-mono.svg   单色图形，同一轮廓，适合单色印刷和遮罩；默认浅柠绿，可更改 color。
logo-lockup.svg      横排“图形 + 造物 STUDIO”，透明背景，242 × 64 viewBox。
favicon.svg         黑色圆角底、浅柠绿标识的网站图标，16 px 起。
preview.html        本地品牌预览，含标识、组合、尺寸与配色。

使用
导航图形建议 32 × 32 CSS px，最低 24 × 24；favicon 最低 16 × 16。
组合标识建议宽 182 px 以上，维持原始比例。
图形四周至少留出 8/64 标识宽度的空白；避免拉伸、描边、投影和重度发光。
中文组合使用系统字体 Microsoft YaHei / PingFang SC / Noto Sans CJK SC，无外部字体请求。

颜色
主色 #D3F28A，亮面 #EDFCCB，暗面 #9EC65B。
深色背景推荐 #141719，品牌文字 #F0F3EC。
浅色底使用单色深灰 #202622；请内联 SVG 后设 color，或修改单色 SVG 的 color 属性。
